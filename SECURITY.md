# Security Policy

## Reporting a vulnerability

Please report security issues privately via GitHub's
[Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(available in the repository's Security tab). This feature must be enabled in
the repository settings after the repository is created on GitHub.

Please do not open public issues, and never post `BOT_TOKEN`, `API_KEY`, or
any other credentials in an issue, discussion, or pull request — even a redacted
one. Live credentials are never needed for an ordinary bug report: reproducible
configuration examples with placeholder values are enough.

## Supported versions

Until the first stable release, only the current state of the default branch
is supported. Older revisions carry no formal support guarantee.
